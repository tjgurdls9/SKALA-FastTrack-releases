SKALA FastTrack은 교재를 올리면 개념을 뽑아 학습 순서를 짜주고, 설명·퀴즈·간격 반복 복습까지 이어주는 학습 보조 앱이에요. 서버가 없고, 분석과 설명 생성은 각자 등록한 AI API 키로 실행돼요(BYOK) — 그래서 API 키를 등록하지 않아도 외부 챗봇(ChatGPT·Claude.ai 등)에 복사·붙여넣기만 하면 똑같이 전체 기능을 쓸 수 있어요. 모든 데이터는 이 컴퓨터에만 저장됩니다.

빠른 시작

1
AI 키 등록하기 (선택)
왼쪽 AI 키 설정에서 Claude·GPT·Gemini 중 하나의 키를 붙여넣고 "이걸로 사용하기"를 누르세요. 외부 챗봇만 쓸 거면 이 단계는 건너뛰어도 돼요.
2
자료 올리기
자료 업로드에서 교재 PDF를 올리고 분석 방식을 고르세요. 끝나면 개념이 소주제별로 쌓여요. 여러 자료를 이어서 올려도 됩니다.
3
개념 정리하고 아는 것 체크하기
개념 점검에서 쪼개진 모듈 → 중복 의심 개념 순으로 합치면 목록이 훨씬 깔끔해져요 (모듈을 먼저 합쳐야 중복이 드러나거든요). 대주제 단위로 "이미 다 아는 내용"을 통째로 체크할 수도 있어요. 다 됐으면 맨 아래 "학습 플랜 만들기"를 누르세요.
4
"오늘은 이것부터"로 시작하기
학습 플랜 맨 위 카드가 오늘 할 3개를 골라줘요. 개념을 눌러도 곧바로 비용이 나가진 않고, 레슨을 어떤 방식으로 만들지 고르는 화면이 먼저 나와요.
5
설명 읽고 퀴즈 풀기
퀴즈까지 풀어야 "학습 완료"로 인정되고 복습 일정이 잡혀요. 채점은 AI 호출 없이 즉시 이뤄집니다.
6
다음 날부터는 "오늘의 복습"
다시 볼 때가 된 개념이 자동으로 모여요. 맞히면 다음 복습이 멀어지고 틀리면 다시 가까워져요. 매일은 이 화면만 확인해도 충분해요.

비용이 나가는 순간

이 세 지점 말고는 API 토큰이 들지 않아요
자료 업로드 → "바로 분석" 트랙 가장 큼

자료를 여러 구역으로 나눠 각 구역마다 AI를 한 번씩 호출해요(400페이지 기준 약 38번, 대략 $2~3 정도로 추정). 실패해서 "다시 시도"를 누르면 처음부터 다시 호출돼요. "외부 챗봇으로 분석" 트랙을 쓰면 이 비용 자체가 없어요.

레슨을 "AI로 바로 만들기"로 열 때

개념 하나당 최초 1회만 AI를 호출해서 설명·다이어그램·퀴즈를 만들어요. 한 번 만들어지면 캐싱되니, 같은 개념을 다시 열어봐도 추가 비용은 없어요. "외부 챗봇으로 만들기"를 쓰면 이 비용도 없어요.

코드 설명의 "전체 설명 보기" 버튼

이 버튼만 누르면 AI를 호출해요. 코드에 마우스를 올렸을 때 뜨는 호버 설명 자체는 이미 분석된 용어집·개념 데이터를 로컬에서 매칭하는 거라 API 호출이 전혀 없어요.

API 토큰이 들지 않는 기능들

메모(포스트잇 보드)

"+ 새 메모"를 누르면 빈 메모가 바로 생기고 곧장 글을 쓸 수 있어요API 호출 없음. 다 썼으면 보드의 빈 바탕을 한 번 눌러 편집을 끝내세요. 그 뒤로는 메모를 끌어서 옮기고, 두 번 누르면 기울기가 바뀌고, 오른쪽 아래 모서리를 끌면 비율을 유지한 채 크기가 바뀌어요. 필요 없어진 메모는 ✕로 지우면 돼요. 전부 이 컴퓨터에만 저장되고, 만드는 즉시 저장되니 쓰다가 나가도 안 사라져요.

자료 업로드

/upload
① 바로 분석 API 키 필요

등록해둔 AI API로 자료 전체를 자동으로 분석해요. 손이 제일 덜 가지만 자료 크기만큼 API 토큰이 들어요.

② 외부 챗봇으로 분석 API 키 불필요

자료를 구역별로 나눠 보여주고, 각 구역마다 안내 프롬프트를 복사해 이미 쓰는 챗봇에 붙여넣은 뒤 답변을 다시 붙여넣으면 우리 앱의 API 호출 없이 반영돼요.

외부 챗봇 트랙, 실제로는 이렇게 동작해요

5단계 중 AI가 실제로 등장하는 건 챗봇에 붙여넣는 순간 딱 한 번이에요. 나머지(파일에서 텍스트를 구역으로 나누기, 프롬프트+원문 복사, 챗봇 답변 파싱, 최종 저장)는 전부 이 컴퓨터에서 처리하는 기계적인 작업이라 API 호출도 비용도 없어요. 자료 파일을 챗봇에 따로 올릴 필요는 없고, 복사한 프롬프트 안에 자료 원문이 이미 들어있어요.

구역을 하나 채우면 그 구역이 자동으로 접히고 다음 미완료 구역이 자동으로 펼쳐져요 — 손으로 다음 아코디언을 찾아 열 필요가 없어요. "지금까지 읽은 내용" 카드가 실시간으로 개념·용어 개수를 보여주고, 챗봇이 자료에 없는 내용을 지어내면 경고와 함께 걸러진 개수를 알려줘요. 마지막 "선후관계"(권장, 생략 가능) 단계까지 채우면 학습 순서가 훨씬 정확해져요.

업로드한 자료 목록

이미지로만 되어 있거나 복사 방지 처리된 PDF는 텍스트가 거의 안 나오면 업로드 시점에 바로 알려드려요. 같은 이름의 자료를 다시 올리면 중복 확인 창이 떠요. 언제든 삭제할 수 있는데, 그 자료에서 나온 개념·레슨·복습 기록까지 함께 사라지는 되돌릴 수 없는 조작이에요.

개념 점검

/concepts
대주제 · 소주제 2단 구조 신규

자료 하나에서 나온 소주제(모듈)들이 의미가 비슷한 것끼리 자동으로 대주제로 묶여요 (대주제 개수는 자료 내용에 따라 자동으로 정해져요). 대주제 헤더를 펼치면 2~3문장 개요와, 필요하면 흐름을 보여주는 관계도가 함께 나오고, 그 아래 소주제 아코디언들이 이어져요. 대주제 옆 "이 대주제는 이미 다 아는 내용이에요" 버튼을 누르면 그 안의 소주제·개념을 통째로 아는 것으로 체크할 수 있어요(다시 누르면 되돌릴 수 있어요). 예전에 대주제 계층이 생기기 전에 분석한 자료는 이 레이어 없이 기존처럼 소주제 아코디언만 평평하게 보여요.

이미 아는 개념 체크 · 제외

체크한 개념은 레슨을 열 때 설명 깊이가 "요약" 쪽으로 시작해요. 체크 초기화는 화면에서만 지우고, 맨 아래 "학습 플랜 만들기 · 업데이트"를 눌러야 실제 반영돼요. "제외"는 자료·개념은 남기고 학습 플랜에서만 빼는 기능이에요 — 누르는 즉시 지금 플랜에서도 사라지고, 언제든 "다시 포함"으로 되돌릴 수 있어요.

새로 추가된 개념 표시

자료를 다시 분석해서 개념이 늘어나면, 새로 생긴 개념이 있는 대주제·소주제가 자동으로 펼쳐지고 해당 줄에 하이라이트가 떠요. 줄을 한 번이라도 누르면(체크·제외 포함) 그 줄만 바로 꺼지고, 이 화면을 벗어나면 남은 것도 전부 자동으로 확인 처리돼요. 여러 개를 한꺼번에 지우고 싶으면 상단 전체확인 버튼을 누르면 즉시 다 꺼져요.

검색

개념이 수백 개로 늘어나면 검색창에 이름 일부만 넣어보세요. 모듈 묶음은 그대로 두고 걸린 개념만 남기며, 검색 중에는 결과가 접힌 모듈 안에 숨지 않도록 자동으로 펼쳐져요.

중복 의심 개념

같은 모듈 안에서 한쪽 이름이 다른 쪽에 통째로 들어있는 경우만 후보로 묶어요(예: "SQL Injection 방어" / "SQL Injection 방어 기법"). 확인하고 "병합"을 누르면 레슨·퀴즈 기록·복습 상태를 대표 개념 쪽으로 옮겨 보존한 채 하나로 합쳐지고, 그룹이 여러 개면 한 번에 전체 병합도 가능해요.

쪼개진 모듈

같은 모듈인데 자료마다 목차 표기가 달라 여러 개로 나뉜 것들을 묶어 보여줘요(예: "JavaScript 기초" / "JavaScript 기초 - 변수"). 합쳐도 개념은 하나도 사라지지 않고 소속 모듈 이름만 바뀌어요. 이 화면에서 병합하면 대주제 그룹핑도 함께 갱신돼서, 병합된 모듈이 대주제 안에서 안 사라져요.

학습 플랜

/plan
순서를 짜는 방식

선후관계를 지키면서 여러 모듈을 4개씩 묶어 번갈아 배치해요(교차 연습). 한 모듈만 몰아서 끝내는 것보다 여러 모듈을 섞어야 더 오래 기억에 남는다는 연구를 반영했어요.

🎯 오늘은 이것부터

개념이 수백 개까지 늘어나면 전체 목록은 시작점이 되기 어려워서, 맨 위에 오늘 할 것만 3개 추려줘요. 고르는 순서는 ① 이미 만들어둔 레슨(추가 비용 없이 바로 학습 가능) ② 선행 개념이 모두 끝난 것 중 중요도 높은 순이에요.

세 그룹 + 검색

목록이 길어지지 않게 레슨 미생성 · 아직 학습하지 않음(기본 펼침) · 학습 완료(기본 접힘) 세 그룹으로 나눠요. 자료가 새로 추가돼서 아직 이번 플랜에 안 들어간 개념이 있으면 "아직 플랜에 없음" 그룹도 나타나고, 눌러서 한 번에 포함시킬 수 있어요. 검색은 개념 이름뿐 아니라 모듈 이름으로도 찾을 수 있어요(예: "JOIN 심화").

레슨 만들기 · 일괄 만들기

각 항목을 누르면 레슨(설명+퀴즈)으로 들어가요. ① AI로 바로 만들기(즉시 호출, 한 번 만들면 캐싱) 또는 ② 외부 챗봇으로 만들기 중 골라 만들 수 있어요. "레슨 미생성" 그룹의 "외부 챗봇으로 한 번에 만들기"를 누르면, 아직 안 만든 레슨을 한 화면에서 개념별로 이어서(자동으로 다음 개념으로 넘어가며) 만들 수 있어요.

플랜 초기화 vs 빼기

"플랜 초기화"는 순서 목록만 지우고 개념·레슨·복습 기록은 남겨요. 항목별 "빼기"는 그 개념 하나만 플랜에서 제외해요(개념 점검의 "제외"와 같은 동작).

오늘의 복습

/review
간격 반복(spaced repetition)

퀴즈를 맞히면 다음 복습 시점이 점점 멀어지고(1일 → 3일 → 8일 …), 틀리면 다시 1일 뒤로 당겨져요. 복습할 때가 된 것과 3일 안에 볼 것만 펼쳐서 보여주고, 그보다 나중 것은 "예정된 복습"을 열어 확인할 수 있어요. 아직 때가 안 된 항목은 흐리게 표시해 클릭을 막아요.

코드 설명

/code-explain
호버 설명 API 호출 없음

코드를 붙여넣으면 밑줄 친 용어에 마우스를 올렸을 때 즉시 설명이 떠요 — 이미 분석해둔 개념·용어집을 이 컴퓨터에서 바로 매칭하는 거라 AI를 부르지 않아요. "Top3"의 "p"처럼 더 긴 단어 속 부분 글자까지는 안 잡히게, 단어 경계가 맞을 때만 매칭돼요.

전체 설명 보기 API 호출함

누르면 AI를 호출해서 전체 요약과 함께, 의미 있는 동작이 있는 줄마다 그 줄이 정확히 뭘 하고 왜 필요한지 한 줄씩 설명해줘요(빈 줄이나 괄호만 있는 줄은 건너뛰어요).

저장 · 인쇄

AI 키 설정

/settings
API 키 등록 · 전환

Claude·GPT·Gemini 중 가진 키를 자유롭게 등록하고, 여러 개를 등록해뒀다가 "이걸로 사용하기"로 바꿔가며 쓸 수도 있어요. 키는 서버가 아니라 이 컴퓨터에 암호화되어 저장돼요(BYOK) — 그래서 여러 명이 함께 써도 비용이 한 사람에게 몰리지 않아요. "삭제"로 언제든 등록을 지울 수 있어요.

앱 버전 · 업데이트 확인

현재 버전과, 새 버전이 있으면 다운로드 링크가 여기 보여요. "업데이트 확인" 버튼으로 언제든 다시 확인할 수 있고, 홈 화면에도 같은 버전 번호가 작게 함께 표시돼요.

자주 헷갈리는 것

개념이 수백 개나 되는데 어디서부터 봐야 하나요?

학습 플랜 맨 위의 "🎯 오늘은 이것부터" 카드만 보시면 돼요. 이미 만들어둔 레슨(추가 비용 없음)을 먼저 권해요. 목록이 너무 길게 느껴진다면 개념 점검에서 대주제 단위로 "이미 다 아는 내용"을 체크해두는 것도 방법이에요.

학습 플랜을 다시 만들면 어떻게 되나요?

플랜은 하나만 유지돼요. 체크를 바꾸고 "학습 플랜 만들기 · 업데이트"를 다시 누르면, 새로 쌓이지 않고 그 자리에서 최신 상태로 갱신돼요.

"플랜 초기화"와 자료 "삭제"는 뭐가 달라요?

플랜 초기화는 순서 목록만 지우고 개념·레슨·복습 기록은 그대로 남아서, 나중에 다시 플랜을 만들면 기존 학습 자산을 그대로 재사용해요. 자료 삭제는 그 자료에서 나온 개념·레슨·복습 기록까지 전부 함께 사라지는 되돌릴 수 없는 조작이에요.

AI 키는 왜 각자 등록해야 하나요?

자료 분석과 학습 콘텐츠 생성에 실제로 AI를 호출하는데, 그 비용을 서버가 아니라 각자 본인의 API 키로 부담하는 구조예요(BYOK). 그래서 여러 명이 써도 누구 한 사람에게 비용이 몰리지 않아요.

API 키 없이도 이 앱을 쓸 수 있나요?

네. 자료 분석과 레슨 생성 둘 다 "외부 챗봇" 트랙을 쓰면 API 키가 아예 없어도 전체 기능을 이용할 수 있어요. 다만 손으로 복사·붙여넣기를 해야 해서 조금 더 손이 가요.

대주제가 이상하게 묶인 것 같으면 어떻게 하나요?

대주제는 소주제 이름만 보고 자동으로 묶는 편의 기능이라, 마음에 안 들면 그냥 무시하고 그 안의 소주제 아코디언만 펼쳐서 봐도 전혀 문제없어요. 소주제·개념 자체는 대주제 묶음과 무관하게 그대로 다 남아있어요.

메모는 어딘가에 안전하게 저장되나요?

네, 이 컴퓨터의 로컬 데이터베이스에만 저장돼요. 만드는 즉시 저장되니 글을 쓰다 나가도 사라지지 않아요. 아무것도 안 쓴 빈 메모도 그대로 남으니, 필요 없으면 ✕로 지워주세요.
