# SKALA FastTrack

SKALA AX 부트캠프 비전공자 수강생을 위한 학습 보조 앱입니다.
교재 PDF를 올리면 개념을 뽑아 학습 순서를 만들고, 설명·퀴즈·간격 반복 복습까지 이어집니다.

이 저장소는 **앱 배포 전용**입니다. 최신 버전은 [Releases](../../releases/latest)에서 받으세요.

## 설치

- **Apple Silicon(M시리즈) Mac**에서 동작합니다.
- 별도 설치 프로그램은 필요 없습니다. 압축을 풀고 `SKALA FastTrack.app`을 응용 프로그램 폴더에 옮기면 됩니다.

### 처음 열 때 — 경고 창이 뜹니다

Apple 개발자 등록을 하지 않은 앱이라 macOS가 첫 실행을 막습니다. 아래 순서로 한 번만 해주면 그 뒤로는 그냥 열립니다.

1. 앱을 더블클릭하면 **"열지 않음"** 창이 뜹니다 → **완료**를 누르세요.
   ⚠️ **휴지통으로 이동**을 누르면 앱이 지워집니다.
2. **시스템 설정 → 개인정보 보호 및 보안**으로 가서 아래로 스크롤하면
   **"그래도 열기"** 버튼이 있습니다. 누르세요.
3. 확인 창에서 **열기** → 로그인 암호를 입력하면 실행됩니다.

## 업데이트

새 버전이 나오면 앱의 **설정** 화면에 알림이 뜹니다.
여기서 새 파일을 받아 기존 앱을 덮어쓰면 되고, **학습 기록은 앱 바깥에 저장돼 있어 그대로 남습니다.**

## 문제가 생기면

`~/SKALA-FastTrack-data/app.log` 파일을 보내주세요. (API 키 같은 민감한 값은 기록되지 않습니다.)
